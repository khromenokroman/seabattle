Журнал изменений seabattle
----------------------------------------------------------------------------------------------------
[+] 0.4.0.0.2026-11-11 core - игровая логика: проверка расстановки (состав, границы, пересечения, касания углом), случайный флот, поле с выстрелами и отметкой клеток вокруг потопленного, партия на двоих (очередь, ещё выстрел после попадания, сдача, победа, история);
[-] 0.3.1.0.2026-11-11 web - игра в двух вкладках: старая показывает «Игра открыта в другом окне» и кнопку «Играть здесь» вместо бесконечного переподключения; второй клик по той же клетке до прихода снимка не отправляется; 401 на выстрел возвращает на старт; при потере сессии из адреса убирается код комнаты;
[+] 0.3.0.0.2026-11-11 web - веб-клиент: создание комнаты и вход по коду или ссылке, расстановка с подсветкой (поворот, случайно, очистить), бой на двух полях, счётчик кораблей противника, сдача, ещё партия, переподключение после обрыва и перезагрузки, светлая и тёмная тема, вёрстка для телефона;
[-] 0.2.1.0.2026-11-11 server - числа вне int в запросах отклоняются с 400 (раньше 4294967299 молча становилось 3); исключение в потоке событий закрывает поток, а не весь процесс; старый поток при открытии нового получает event: closed (две вкладки больше не отбирают поток друг у друга); не больше 1000 комнат сразу, сверх - 503;
[+] 0.2.0.0.2026-11-11 server - игровой сервер: комнаты на двоих по коду, токены игроков, расстановка, выстрелы, сдача, ещё партия, выход, снимки состояния по SSE (/api/events), удаление комнат без игроков через 30 минут, служба на порту 8090;
[+] 0.1.0.0.2026-11-11 core - каркас проекта: интерфейс игровой логики (поле, флот, партия), протокол клиента и сервера, сборка и пакет deb;
