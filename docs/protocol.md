# Протокол seabattle

Клиент (браузер) и сервер общаются по HTTP: действия через `POST` с JSON, события от сервера через
Server-Sent Events (`GET /api/events`, в браузере `EventSource`). Сервер хранит оба поля и проверяет
каждое действие, клиент получает только то, что игроку положено видеть.

Все тела запросов и ответов в JSON, кодировка UTF-8. Сервер отдаёт статику клиента с `/`.

## Координаты и корабли

- Поле 10×10. `x` - столбец 0..9 (подписи А Б В Г Д Е Ж З И К), `y` - строка 0..9 (подписи 1..10).
- Корабль: `{"x": 2, "y": 3, "len": 4, "dir": "h"}`. `x`,`y` - начальная клетка (левая для `"h"`, верхняя
  для `"v"`), `dir` - `"h"` (вправо) или `"v"` (вниз). Для `len` 1 `dir` любой.
- Флот: 1×4, 2×3, 3×2, 4×1 (всего 10 кораблей). Корабли не пересекаются и не касаются ни сторонами, ни
  углами. Состав флота также приходит в снимке (`fleet`).

## Ошибки

Ошибка - HTTP-код и тело `{"error": "текст на русском для игрока"}`.

| Код | Когда |
|---|---|
| 400 | неправильный JSON, нет поля, координаты вне поля, расстановка не по правилам |
| 401 | неизвестный `token` (комната удалена или игрок вышел) |
| 404 | комнаты с таким кодом нет |
| 409 | действие не ко времени: комната занята, не твой ход, по клетке уже стреляли, флот уже расставлен |
| 503 | на сервере уже 1000 комнат, новую создать нельзя (вход в существующую работает) |

## Запросы

### `GET /api/version`
`{"version": "0.1.0.0"}`

### `GET /api/share` - адрес для ссылки-приглашения
`{"public_url": "", "addresses": ["192.168.88.10", "10.0.0.5"]}`

Клиент, открытый по `localhost`, `127.*`, `0.0.0.0` или `::1`, не может отдать сопернику свой адрес,
поэтому строит ссылку из этих данных:
- `public_url` - адрес из параметра сервера `--public-url` (прокси, Docker); если не пустой, ссылка
  `<public_url>/#<код>`, адреса не нужны;
- `addresses` - IPv4-адреса сервера в сети (работающие интерфейсы без loopback и без мостов docker,
  libvirt и veth), частные сети первыми; ссылка `<протокол>//<адрес>:<порт страницы>/#<код>`. В
  контейнере (есть `/.dockerenv`) список пустой: адреса контейнера снаружи недоступны.

Открытый по другому адресу клиент берёт адрес страницы и этот запрос не делает.

### `GET /api/random-fleet`
Случайная правильная расстановка, чтобы показать её игроку перед отправкой.
`{"ships": [<корабль>, ...]}`

### `POST /api/rooms` - создать комнату
Запрос: `{"name": "Рома"}` (имя 1..20 символов после обрезки пробелов).
Ответ: `{"room": "K7M2", "token": "<32 hex>", "player": 0}`.

`room` - код из 4 символов (латинские заглавные буквы без I, O и цифры 2..9), его сообщают второму игроку.
`token` - секрет игрока: передаётся во всех остальных запросах. Клиент хранит `room` и `token` в
`localStorage`, чтобы после перезагрузки страницы вернуться в игру.

### `POST /api/rooms/{room}/join` - войти в комнату
Запрос: `{"name": "Лиза"}`. Код комнаты без учёта регистра.
Ответ: как у создания, `player` - занятое место: 1, или 0, если из комнаты вышел создатель.
Ошибки: 404 - нет комнаты, 409 - в комнате уже двое.

### `GET /api/me?token=<token>` - проверить сохранённый токен
Ответ: `{"room": "K7M2", "player": 0, "name": "Рома"}` или 401. Клиент вызывает его при загрузке страницы,
если в `localStorage` есть токен, и при ошибке `EventSource` (поток не сообщает код ответа): 401 - забыть
токен и показать стартовый экран, иначе подождать и переподключиться.

### `GET /api/events?token=<token>` - поток событий
`Content-Type: text/event-stream`. Сразу после подключения и после каждого изменения в комнате сервер
шлёт снимок:

```
event: state
data: {...снимок...}

```

Каждые 15 секунд строка-комментарий `: ping` (держит соединение). Неизвестный `token`: ответ 401 без
потока. После `POST /api/leave` и при остановке сервера поток просто закрывается.

Если для того же `token` открыт новый поток (игра открыта в другой вкладке или на другом устройстве),
старый получает последнее событие и закрывается:

```
event: closed
data: {"reason": "replaced"}

```

Клиент, получивший `closed`, не переподключается сам: иначе две вкладки будут бесконечно отбирать поток
друг у друга. Он показывает «Игра открыта в другом окне» и переподключается только по действию игрока.

### `POST /api/place` - расставить флот
Запрос: `{"token": "...", "ships": [<корабль> x 10]}`. Ответ: `{"ok": true}`.
Можно только в фазе `placing` и один раз за партию. Когда расставили оба, начинается `playing`.

### `POST /api/fire` - выстрел
Запрос: `{"token": "...", "x": 4, "y": 7}`. Ответ: `{"result": "miss" | "hit" | "sunk"}`.
Попал (`hit`, `sunk`) - стреляешь ещё, промахнулся - ход переходит. Вокруг потопленного корабля клетки
отмечаются промахами автоматически, стрелять в них нельзя (409).

### `POST /api/resign` - сдаться
Запрос: `{"token": "..."}`. Ответ: `{"ok": true}`. Можно в `placing` и `playing`, побеждает противник.

### `POST /api/rematch` - сыграть ещё
Запрос: `{"token": "..."}`. Ответ: `{"ok": true}`. Только в `finished`. Когда попросили оба - новая
партия в фазе `placing`, первым стреляет проигравший прошлой партии.

### `POST /api/leave` - выйти из комнаты
Запрос: `{"token": "..."}`. Ответ: `{"ok": true}`. Токен перестаёт действовать. Если игра шла, она
засчитывается как сдача. Оставшийся игрок видит `opponent: null` и фазу `waiting`: в комнату может войти
новый игрок, начинается новая партия. Пустая комната удаляется.

## Снимок состояния

Снимок строится для конкретного игрока: `you` - он, `opponent` - противник.

```json
{
  "room": "K7M2",
  "you": {"name": "Рома", "player": 0},
  "opponent": {"name": "Лиза", "connected": true},
  "phase": "playing",
  "placed": {"you": true, "opponent": true},
  "turn": "you",
  "winner": null,
  "resigned": false,
  "rematch": {"you": false, "opponent": false},
  "fleet": [4, 3, 3, 2, 2, 2, 1, 1, 1, 1],
  "own": {
    "ships": [{"x": 0, "y": 0, "len": 4, "dir": "h", "sunk": false}],
    "shots": [{"x": 5, "y": 5, "hit": false}]
  },
  "enemy": {
    "shots": [{"x": 1, "y": 2, "hit": true}],
    "sunk": [{"x": 1, "y": 2, "len": 1, "dir": "h"}],
    "ships": []
  },
  "last_shot": {"by": "you", "x": 1, "y": 2, "result": "sunk"}
}
```

| Поле | Значение |
|---|---|
| `opponent` | `null`, пока второй не вошёл; `connected` - открыт ли у него поток событий |
| `phase` | `waiting` (нет второго игрока), `placing`, `playing`, `finished` |
| `placed` | кто расставил флот в текущей партии |
| `turn` | `"you"`, `"opponent"`; `null` вне `playing` |
| `winner` | `"you"`, `"opponent"`; `null` вне `finished` |
| `resigned` | партия кончилась сдачей (или выходом) |
| `rematch` | кто нажал «Ещё партию» (только в `finished`) |
| `own.ships` | мои корабли (пусто, пока не расставил), `sunk` - потоплен ли |
| `own.shots` | все отмеченные клетки моего поля: выстрелы противника и промахи вокруг потопленных |
| `enemy.shots` | все отмеченные клетки поля противника |
| `enemy.sunk` | потопленные корабли противника |
| `enemy.ships` | все корабли противника, только в `finished` (показать, где стояли), иначе `[]` |
| `last_shot` | последний выстрел партии или `null` |

Комната удаляется через 30 минут, если ни у одного игрока нет открытого потока событий.
